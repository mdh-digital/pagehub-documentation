# File Manager

Tempat semua gambar dan berkas media organisasimu. Buka lewat **File Manager** di sidebar.

<Shot src="/img/media/file-manager.webp" wide>
File Manager dalam tampilan grid: baris jejak folder di atas (Beranda › Produk), kartu-kartu folder dan gambar dengan thumbnail, kotak pencarian, pemilih urutan dan tampilan grid/baris di kanan atas, serta bilah "Pemakaian Storage" di bawah.
</Shot>

## Mengunggah

Tiga cara:

- Klik tombol unggah.
- **Seret berkas** langsung ke area file — muncul penanda *"Lepaskan untuk mengunggah"*.
- Dari dalam editor, lewat panel properti gambar atau panel **Pilih gambar**.

Batasnya: gambar, maksimal **8 MB** per berkas. Unggahan yang sedang jalan bisa dibatalkan.

## Folder

**Buat Folder** membuat folder baru di lokasi yang sedang kamu buka. Folder bisa bersarang.

Menghapus folder:

- Berkas di dalamnya **dipindahkan ke Beranda**, nggak ikut terhapus.
- **Subfolder ikut terhapus.**

PageHub selalu menyebutkan berapa item yang terdampak sebelum kamu mengonfirmasi.

## Aksi berkas

| Aksi | Keterangan |
| --- | --- |
| **Salin URL** | Salin alamat berkas — tempel di HTML atau di panel properti |
| **Ganti nama** | Ubah nama tampilannya |
| **Pindahkan** | Ke folder lain, lewat dialog pemilih folder |
| **Hapus** | Permanen |

Beberapa berkas bisa dipilih sekaligus (centang) untuk dipindah atau dihapus bersama.

::: warning Menghapus gambar yang sedang dipakai
Kalau sebuah gambar dipakai di halaman, PageHub memperingatkan: *"dipakai di 3 page. Hapus tetap? Gambar di page itu akan rusak."* Halaman yang memakainya nggak ikut diperbaiki otomatis — kamu perlu menggantinya sendiri.
:::

## Mencari & mengurutkan

Kotak cari mencakup nama berkas **dan** folder. Urutan: Terbaru, Nama A–Z, atau Ukuran terbesar. Tampilan bisa **grid** atau **baris**.

## Penyimpanan

Bilah **Pemakaian Storage** menunjukkan berapa yang terpakai dari kuota paketmu (`120 MB dari 2 GB`), atau *"Tanpa batas"* kalau paketmu nggak dibatasi.

Kalau penuh, ada dua jalan: hapus berkas yang nggak dipakai, atau beli **Storage Add-On** lewat **Billing → Storage Add-On**.

## Ruang lingkup workspace

File Manager mengikuti [workspace](/team/workspaces) yang sedang aktif:

- **Owner/admin organisasi** melihat seluruh media organisasi, dan bisa mempersempit ke satu workspace.
- **Anggota biasa** cuma melihat media di workspace yang di-grant ke dia. Tanpa grant sama sekali, hasilnya kosong — bukan seluruh organisasi.

Aturan ini sengaja lebih ketat daripada bagian lain aplikasi: media adalah satu-satunya tempat di mana "tampilkan semua kalau ragu" bakal membocorkan berkas klien lain.

## Media per website

Tiap website punya tab **Assets** sendiri yang menampilkan media terkait website itu — jalan pintas supaya kamu nggak perlu menyisir seluruh File Manager.

## Media dari template

Waktu kamu memakai [template](/website/website-templates), gambar-gambar di dalamnya **disalin** ke File Manager organisasimu (di folder bernama sama dengan alamat website barunya), dan tautan di HTML diarahkan ke salinan itu. Jadi salinanmu nggak pernah tergantung pada berkas milik orang lain.
