# كتابة المقالات

افتح الموقع ← تبويب **المدوّنة** ← **المقالات** ← **اكتب مقالًا**.

<Shot src="/img/blog/article-editor.webp" wide>
محرّر المقالات: حقل العنوان في الأعلى، ومحرّر نص غني لجسم المقال في الوسط (شريط فيه العناوين والغامق/المائل والقوائم والاقتباس والشيفرة والرابط والصورة)؛ واللوحة الجانبية فيها النشر (منشور / مسودّة / مجدول) والتصنيف. أزرار «اكتب بالذكاء الاصطناعي» والإلغاء والحفظ في الأعلى؛ وبطاقة تحسين الظهور أسفل جسم المقال.
</Shot>

## الحقول

| الحقل | ملاحظات |
| --- | --- |
| **العنوان** | إلزامي. يُشتقّ المعرّف منه إن لم تضبطه |
| **الوصف** | وسم تحسين الظهور — يظهر في نتائج البحث وعلى بطاقات قائمة المقالات |
| **جسم المقال** | نص غني: عناوين، عريض/مائل، قوائم، روابط، صور، اقتباسات |
| **المعرّف (الرابط)** | تلقائي من العنوان؛ قابل للتعديل |
| **التصنيف** | من قائمة تبويب التصنيفات |
| **الصورة المصغّرة** | صورة بطاقة المقال ومعاينة المشاركة |
| **الكلمات المفتاحية** | اكتب ثم Enter أو فاصلة |

وهناك أيضًا خيار **«استخدم هذه الصورة أيقونةً لصفحة المقال»** — وإن لم تفعّله يستخدم المقال أيقونة الموقع.

## الحالة والجدولة

في لوحة **النشر**:

- **اجعلها منشورة** — يُنشر المقال.
- **اجعلها مسودّة** — يُخفى.
- **انشر في** — اختر تاريخًا ووقتًا مستقبليًا. يبقى المقال مخفيًا حتى موعده ثم **يُنشر نفسه**.

مفيد لتجهيز عدّة مقالات دفعة واحدة وإطلاقها تدريجيًا.

## الكتابة بالذكاء الاصطناعي

زر **اكتب بالذكاء الاصطناعي** في محرّر المقالات.

1. املأ **عمّ يتحدّث؟** — مثلًا `كيف تختار فيلا لرحلة شركة من 50 شخصًا`.
2. اضغط **اكتب**.

يكتب الذكاء الاصطناعي **العنوان والوصف والكلمات المفتاحية والجسم**، و**يختار تصنيفًا** من قائمتك القائمة. ويقرأ أيضًا الموجز الهوياتي للموقع، فتتطابق النبرة مع بقية الموقع.

::: warning هذا يستبدل ما هو موجود الآن
سيُستبدل العنوان والوصف والكلمات المفتاحية والجسم في النموذج. فإن كنت قد كتبت شيئًا فانسخه أولًا.
:::

و**راجع دائمًا قبل الحفظ**: الذكاء الاصطناعي لا يعرف حقائق عملك، فالأرقام والأسماء والأسعار وأي ادّعاءات تحتاج تدقيقًا.

يستهلك [أرصدة الذكاء الاصطناعي](/ar/ai/credits).

## جداول المدوّنة بالذكاء الاصطناعي

تبويب **المدوّنة ← جدول الذكاء الاصطناعي** ينتج مقالات بوتيرة منتظمة دون أن تكتب كلًا منها.

<Shot src="/img/blog/blog-schedule.webp">
تبويب جدول الذكاء الاصطناعي: جدول بأعمدة الجدول والتقدّم والناتج والتشغيل التالي؛ وزر «جدول جديد» في الأعلى. أحد الصفوف يعرض حالة «فعّال» مع «مقالان كل أسبوع».
</Shot>

إنشاء جدول:

| الحقل | ملاحظات |
| --- | --- |
| **الاسم** | لك، مثل `محتوى الفيلات للربع الثالث` |
| **محاور المحتوى واتجاهه** | الموجز: عمّ يتحدّث، لمن، وبأي نبرة. كلّما زاد التحديد قلّت العمومية |
| **الناتج** | **حفظ كمسودّة** أو **نشر مباشر** |
| **مقالات لكل تشغيل** | كم مقالًا في كل مرّة |
| **كل … (يوم/أسبوع/شهر)** | الوتيرة |
| **البداية / النهاية** | اختياري. الفراغ = ابدأ الآن / بلا نهاية |

ثم **خطّط العناوين بالذكاء الاصطناعي** لملء **الطابور**: قائمة العناوين المزمع كتابتها. ويمكنك تحرير الطابور، أو كتابة عناوينك.

يُسجَّل كل تشغيل في **السجل**، فتعرف دائمًا ما جرى.

يمكن **إيقاف** الجداول مؤقتًا و**استئنافها** متى شئت. وحذف جدول يزيل طابوره وسجلّه — أما المقالات المكتوبة فتبقى.

::: tip ابدأ بالمسودّات
في جدولك الأول اختر **حفظ كمسودّة**. اقرأ بعض النتائج، وحسّن الموجز، ولا تنتقل إلى **نشر مباشر** إلا حين تثق بالجودة.
:::

تخطيط العناوين وكتابة كل مقال يستهلكان أرصدة. ويُعرض التقدير في النموذج قبل حفظ الجدول.

## قائمة المقالات

يعرض تبويب **المقالات** كل مقال بعنوانه وتصنيفه وعدد مشاهداته ووقت آخر تحديث. وفيه حقل بحث، وعلامة **مجدول** للمقالات المنتظرة موعد نشرها.
