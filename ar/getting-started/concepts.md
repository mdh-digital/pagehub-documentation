# المفاهيم الأساسية

عشر دقائق هنا توفّر عليك وقتًا كثيرًا لاحقًا. معظم الالتباس في PageHub سببه شيء واحد: عدم معرفة ما الذي يملك ماذا.

## التسلسل

```
Organisation        ← حساب الاشتراك (الباقة، الحصص، الفواتير)
 ├── Members        ← الأشخاص العاملون في هذا الحساب
 ├── Workspace      ← حاوية لكل عميل / لكل مشروع
 │    ├── Website   ← مجموعة صفحات، مظهر واحد، قائمة واحدة
 │    │    └── Page
 │    ├── Landing page
 │    └── Media
 └── Plan & quota
```

### المنظّمة

المنظّمة هي **حساب الاشتراك**. هي التي تملك الباقة والحصص وسجلّ الفواتير — لا أنت كشخص. كل موقع وصفحة وملف مملوك للمنظّمة، فإذا غادر أحد الأعضاء يبقى العمل في مكانه.

يمكن للمستخدم الواحد أن ينتمي إلى أكثر من منظّمة (مثلًا الوكالة التي تعمل بها إضافة إلى حسابك الشخصي). بدّل بينها من قائمة الحساب أسفل الشريط الجانبي.

### مساحة العمل

مساحة العمل هي **حاوية لكل عميل أو مشروع** داخل المنظّمة الواحدة. المواقع وصفحات الهبوط والوسائط تعيش داخل مساحة عمل، ولكل مساحة **عنوانها العام الخاص**.

وهي أيضًا ما يحدّد من يرى ماذا: العضو الذي مُنح صلاحية على مساحة عمل واحدة لا يرى سواها. التفاصيل: [مساحات العمل](/ar/team/workspaces).

### الموقع مقابل صفحة الهبوط

|  | الموقع | صفحة الهبوط |
| --- | --- | --- |
| عدد الصفحات | كثيرة | واحدة |
| الترويسة والتذييل | مشتركة (shell) | داخل الصفحة نفسها |
| المظهر وCSS | عام للموقع كله | لكل صفحة على حدة |
| قائمة التنقّل | موجودة | غير موجودة |
| وحدتا المدوّنة والمتجر | متاحتان | غير متاحتين |
| مناسب لـ | مواقع تبقى طويلًا | حملات تأتي وتذهب |

في العمق كلاهما الشيء نفسه — «صفحة». صفحة الهبوط هي ببساطة صفحة غير مرتبطة بأي موقع.

### الصفحات

محتوى الصفحة يُخزَّن بصيغة **HTML**. هذا هو مصدر الحقيقة. والنتيجة مريحة: أيًا كان ما تفعله — سحب كتلة في الوضع المرئي، أو الكتابة في وضع الشيفرة، أو طلب تعديل من الذكاء الاصطناعي — كل ذلك ينتهي بكتابة HTML نفسه. لا صيغة سرّية تحتجزك.

لذلك للمحرّر ثلاثة أوضاع يكمّل بعضها بعضًا: [المرئي](/ar/editor/visual-mode) و[الشيفرة](/ar/editor/code-mode) و[محادثة الذكاء الاصطناعي](/ar/editor/ai-chat).

### الـ shell: الترويسة والتذييل

داخل الموقع، تُخزَّن الترويسة والتذييل **مرّة واحدة** على مستوى الموقع (يسمّى ذلك *shell*)، لا مكرّرة في كل صفحة. كل صفحة تخزّن محتواها فقط. وعند فتح الزائر لصفحة، يركّب PageHub الثلاثة معًا: ترويسة + محتوى + تذييل.

النتيجة: تغيير الشعار في الترويسة يُنجَز لثلاثين صفحة دفعة واحدة. راجع [الترويسة والتذييل](/ar/website/header-footer).

## مسودّة أم منشورة

لكل صفحة حالتان:

- **مسودّة** — يراها فريقك وأنت فقط. آمنة للعمل عليها أيامًا.
- **منشورة** — متاحة لكل من يملك العنوان.

تريد عرض مسودّة على عميل دون نشرها؟ استخدم **رابط المشاركة** (تبويب المشاركة) — رابط سرّي للقراءة فقط يعمل دون تسجيل دخول ويعرض المسودّة. راجع [نشر الصفحة](/ar/editor/publishing).

## العناوين العامة

يتكوّن عنوانك من **مساحة العمل** + **الموقع** + **الصفحة**:

```
https://<workspace>.pagehub.id/<website>/<page>
https://<workspace>.pagehub.id/<website>          ← الصفحة الرئيسية للموقع
https://<workspace>.pagehub.id/p/<landing-page>   ← صفحة هبوط
```

في بعض التنصيبات يأخذ العنوان شكل مسار بدل النطاق الفرعي:

```
https://app.pagehub.id/w/<workspace>/<website>/<page>
```

كلاهما يشير إلى المحتوى نفسه. وحين يكون للموقع [نطاق مخصّص](/ar/website/custom-domain) موثّق، يصير العنوان أقصر:

```
https://yourdomain.com/<page>
```

::: warning العناوين القديمة ‎/s/‎ و‎/p/‎
المواقع التي أُنشئت قبل نظام العناوين المرتبط بمساحات العمل ما زالت تستجيب على عناوينها القديمة — تُحوَّل تحويلًا دائمًا (301) إلى العناوين الجديدة. الروابط المنتشرة لن تتعطّل، لكن استخدم العنوان الجديد في كل ما تنشره من الآن.
:::

## الحصص وأرصدة الذكاء الاصطناعي

تحكم باقتك أمرين مختلفين يُخلط بينهما كثيرًا:

- **الحصّة** — كم موقعًا وصفحة هبوط ومساحة عمل وعضوًا ومساحة تخزين يُسمح بوجودها. حدّ على *العدد*، يُفحص عند كل إنشاء.
- **أرصدة الذكاء الاصطناعي** — مخصّصك لاستخدام الذكاء الاصطناعي. كل توليد صفحة أو تعديل عبر المحادثة أو مقال مكتوب يستهلك أرصدة بحسب حجم النص المعالَج.

التفاصيل: [الباقات والحصص](/ar/account/plans-and-quota) و[أرصدة الذكاء الاصطناعي](/ar/ai/credits).

## الأدوار

| الدور | الصلاحيات |
| --- | --- |
| **مالك / مدير المنظّمة** | كل شيء، بما فيه الفوترة والأعضاء ومساحات العمل والهوية |
| **عضو** | مساحات العمل والمواقع المسندة إليه فقط |
| **محرّر** (لكل موقع/مساحة) | العرض والتعديل |
| **مشاهد** (لكل موقع/مساحة) | العرض فقط — يُفتح المحرّر في وضع القراءة |

الصلاحيات **تراكمية**: يرى الشخص اتحاد ما أُسند إليه لكل عنصر **مع** محتوى مساحات عمله. التفاصيل: [الأعضاء والصلاحيات](/ar/team/members-and-access).
