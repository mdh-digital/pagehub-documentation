# إنشاء صفحة هبوط

صفحة الهبوط هي **صفحة واحدة مستقلّة**: عنوان واحد، ورسالة واحدة، مبنيّة لحملة واحدة. غير مرتبطة بأي موقع، فلا تتبع مظهرًا، ولا تحصل على قائمة، ولا تتشارك ترويستها وتذييلها مع أحد.

وإن كنت تحتاج أكثر من صفحة، فما تريده [موقع](/ar/website/create-website).

## ثلاث طرق للبدء

افتح **صفحات الهبوط** ← **صفحة هبوط جديدة**.

<Shot src="/img/landing/new-landing-options.webp">
شاشة «صفحة هبوط جديدة» بثلاث بطاقات: استخدام قالب، البناء بالذكاء الاصطناعي، البدء من الصفر، لكل منها أيقونة وسطر تعريفي.
</Shot>

| | ما تحصل عليه | أرصدة الذكاء الاصطناعي |
| --- | --- | --- |
| **استخدام قالب** | صفحة جاهزة من المعرض | لا تُستهلك |
| **البناء بالذكاء الاصطناعي** | صفحة مبنيّة من وصف حملتك | تُستهلك |
| **البدء من الصفر** | صفحة فارغة | لا تُستهلك |

### البناء بالذكاء الاصطناعي

1. **العنوان** (اختياري) — إن تركته فارغًا يقترحه الذكاء الاصطناعي.
2. **عمّ تتحدّث صفحة الهبوط؟** — صِف الهدف والمحتوى. مثال:

   > صفحة هبوط لعرض دورة طبخ عبر الإنترنت. الجمهور ربّات المنازل. واجهة بخصم 50%، ومزايا الدورة، ومنهج مختصر، وآراء، وأسعار، ونموذج تسجيل.

3. تابع.

يسأل الذكاء الاصطناعي بضعة أسئلة، ثم يضع خطة أقسام، ثم يكتب الصفحة قسمًا قسمًا. راجع [كيف يبني الذكاء الاصطناعي الصفحة](/ar/ai/how-generation-works).

::: tip صفحات الهبوط لا تقرأ الموجز الهوياتي للموقع
المواقع تخزّن موجزًا هوياتيًا يرافق كل توليد تلقائيًا. أما صفحة الهبوط فقائمة بذاتها، لذا يجب أن يوجد كل التوجيه — الألوان والنبرة والجمهور — في أمرها الخاص.
:::

### البدء من الصفر

**اسم الصفحة** و**العنوان** فقط. تكون الصفحة فارغة وتبنيها في المحرّر.

## العنوان العام

```
https://<workspace>.pagehub.id/p/<slug>
```

المقطع `p` هو ما يفصلها عن المواقع. لذلك لا يمكن استخدام `p` عنوانًا لموقع.

معرّفات صفحات الهبوط فريدة على مستوى مساحة العمل.

## الفرق عن صفحة الموقع

| | صفحة الهبوط | صفحة الموقع |
| --- | --- | --- |
| الترويسة والتذييل | داخل الصفحة نفسها | من الـ [shell](/ar/website/header-footer) المشترك |
| المظهر | خاص بها | مظهر الموقع العام |
| القائمة | لا توجد | تُحقن قائمة الموقع |
| المدوّنة والمتجر | غير متاحين | متاحان |
| الحصّة | حصّة **صفحات الهبوط** | حصّة **المواقع** |
| لوحة الكتل | لكل صفحة | مشتركة عبر الموقع |

حصّتا المواقع وصفحات الهبوط تُحسبان **منفصلتين** — امتلاء حصّة المواقع لا يمنعك من إنشاء صفحات هبوط.

## تبويبات صفحة الهبوط

افتح صفحة هبوط من قائمتها:

| التبويب | المحتوى |
| --- | --- |
| **الصفحة** | المعاينة وزر التعديل |
| **الإعدادات** | الاسم والعنوان والتتبّع والبكسل والحذف |
| **العملاء المحتملون** | رسائل النماذج من هذه الصفحة |
| **المشاركة** | رابط المعاينة والمتعاونون |

## إدارة القائمة

تعرض شاشة **صفحات الهبوط** كل صفحات مساحة العمل النشطة — مع بحث وترتيب (الأحدث تعديلًا / الاسم / الأكثر مشاهدة)، وقائمة ⋯ لكل بطاقة تقدّم **نسخ** و**نسخ الرابط** و**تنزيل ZIP** و**حذف**.
