# التعرّف على المحرّر

المحرّر هو المكان الذي تقضي فيه معظم وقتك في PageHub. صفحة واحدة، وثلاث طرق لتحريرها، وكلها تكتب في شيفرة HTML نفسها.

<Shot src="/img/editor/overview.webp" wide>
محرّر الصفحات بعرض كامل: شريط أدوات علوي فيه زر رجوع وعنوان الصفحة ومعرّفها، وثلاثة أزرار أوضاع (مرئي، شيفرة، ذكاء اصطناعي)، ومحدّد حجم الشاشة، ومؤشّر «محفوظ»، وزرا الحفظ والنشر. لوحة المخطّط على الجانب، ولوحة الخصائص على الجانب الآخر.
</Shot>

## الأوضاع الثلاثة

| الوضع | لماذا |
| --- | --- |
| **مرئي** | اضغط عنصرًا، غيّر نصّه/لونه/تباعده، واسحبه. [التفاصيل](/ar/editor/visual-mode) |
| **شيفرة** | HTML خام. لمن يعرف تمامًا ما يريد تغييره. [التفاصيل](/ar/editor/code-mode) |
| **ذكاء اصطناعي** | محادثة. اطلب التغييرات بلغة عادية. [التفاصيل](/ar/editor/ai-chat) |

بدّل بينها متى شئت. التغيير في وضع يظهر فورًا في البقية — لأن المخزَّن شيء واحد: شيفرة الصفحة.

يُفتح المحرّر في الوضع **المرئي** افتراضيًا.

## شريط الأدوات

بالترتيب:

- **العودة إلى الموقع** / **العودة إلى صفحات الهبوط** — الخروج من المحرّر.
- **عنوان الصفحة** و**معرّفها**. كلاهما قابل للتحرير هنا.
- **تبديل الصفحة** — الانتقال إلى صفحة أخرى في الموقع نفسه دون مغادرة المحرّر.
- **تراجع / إعادة**.
- **الوضع**: مرئي · شيفرة · ذكاء اصطناعي.
- **حجم الشاشة**: سطح المكتب · لوحي · هاتف — يغيّر عرض اللوحة لا الصفحة نفسها.
- **تحديث المعاينة** — حين تبدو المعاينة غير متزامنة.
- **أدوات أخرى** (⋯) — انظر أدناه.
- **حالة الحفظ**: *غير محفوظ* ← *يُحفظ…* ← *محفوظ* ← *فشل الحفظ*.
- **حفظ** و**نشر**.

## أدوات أخرى (⋯)

| العنصر | ماذا يفعل |
| --- | --- |
| **تحسين الظهور والمظهر** | العنوان والوصف والكلمات المفتاحية وصورة المشاركة والأيقونة والصورة المصغّرة. [التفاصيل](/ar/editor/page-seo) |
| **سجل النسخ** | لقطات للصفحة يمكن استعادتها. [التفاصيل](/ar/editor/history) |
| **رسائل النماذج** | ما وصل من هذه الصفحة |
| **حفظ كقالب** | تحويل هذه الصفحة إلى قالب قابل لإعادة الاستخدام |
| **تنزيل ZIP (html/css/js)** | تصدير الصفحة كملفات |
| **اختصارات لوحة المفاتيح** | قائمة الاختصارات |

## الحفظ

- **حفظ** (<kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>S</kbd>) يحفظ مسودّة. غير منشورة.
- **نشر** يحفظ **وينشر**.

الصفحة المنشورة تحتاج **نشرًا** بعد كل تعديل — فإن اكتفيت بـ **حفظ** فسيظل الزوّار يرون النسخة القديمة. راجع [نشر الصفحة](/ar/editor/publishing).

## صفحات المواقع مقابل صفحات الهبوط

إن كانت هذه الصفحة ضمن موقع وله [shell](/ar/website/header-footer)، يعرض المحرّر ملاحظة:

> الترويسة والتذييل مشتركان من shell الموقع. هنا تحرّر المحتوى فقط.

وزر **تعديل الـ shell** بجوارها ينقلك إلى محرّرهما. وتظل المعاينة تعرض الصفحة **مع الـ shell**، فما تراه هو ما يراه الزائر.

صفحات الهبوط بلا shell — كل شيء، من الترويسة إلى التذييل، داخل الصفحة.

## وضع القراءة فقط

إن كانت صلاحيتك على هذه الصفحة **مشاهد**، يعرض الشريط شارة **وضع العرض** وتُعطَّل كل أدوات التحرير. يمكنك التصفّح وفتح المعاينة والتنقّل بين الصفحات.

## اختصارات لوحة المفاتيح

| الاختصار | الإجراء |
| --- | --- |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>S</kbd> | حفظ |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Z</kbd> | تراجع |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | إعادة |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | نسخ / قص / لصق عنصر |
| <kbd>Delete</kbd> | حذف العنصر المحدّد |

اختصارات العناصر تعمل في الوضع **المرئي** فقط. القائمة الكاملة في ⋯ ← **اختصارات لوحة المفاتيح**.
