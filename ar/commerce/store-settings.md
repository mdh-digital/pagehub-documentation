# إعدادات المتجر

كل ما ليس كتالوجًا ولا طلبًا: هوية المستندات والعملة والعناوين والحسابات والبريد وبوابة الدفع.

## إعدادات المتجر

**المتجر ← إدارة المتجر ← إعدادات المتجر**.

<Shot src="/img/commerce/store-settings.webp">
صفحة إعدادات المتجر: قسم الهوية (اسم الفرع، الهاتف، البريد، الشعار، شعار الفاتورة)، وقسم العملة، وقسم المستندات (مهلة السداد، ملاحظة الفاتورة، تنبيه إذن التسليم، تذييل المستند)، وقسم المدفوعات بمفتاح التحويل البنكي اليدوي.
</Shot>

### الهوية

تُطبع في رأس كل فاتورة وإيصال وإذن تسليم.

| الحقل | ملاحظات |
| --- | --- |
| **اسم الفرع** | إن تُرك فارغًا تستخدم المستندات اسم الموقع أو صفحة الهبوط التي جاء منها الطلب |
| **الهاتف**، **البريد** | بيانات التواصل المطبوعة |
| **الشعار** | شعار المتجر |
| **شعار الفاتورة** | للطباعة فقط. الفراغ يعني اتّباع الشعار الرئيسي |

### العملة

العملة التي يفوتر بها هذا المتجر.

::: warning تغيير العملة لا يحوّل الأسعار
تُخزَّن الأسعار كما كتبتها تمامًا — وتغيير العملة يبدّل التسمية فقط. فـ `150000` التي كانت روبية ستُقرأ `150000` دولارًا. اضبط العملة **قبل** ملء الكتالوج.
:::

### المستندات

| الحقل | ملاحظات |
| --- | --- |
| **مهلة السداد** | أيام بعد تاريخ الطلب. الصفر يعني بلا تاريخ استحقاق |
| **ملاحظة الفاتورة** | مثل «يُرجى السداد قبل تاريخ الاستحقاق.» |
| **تنبيه إذن التسليم** | مثل «يُرجى فحص البضاعة عند الاستلام.» |
| **تذييل المستند** | مثل «شكرًا لثقتكم.» |

### المدفوعات

**التحويل البنكي اليدوي** مفعّل افتراضيًا بمجرّد تفعيل المتجر: يحوّل المشتري إلى أحد حساباتك ثم تؤكّد أنت. ويمكن إطفاؤه إن كنت تريد مدفوعات البوابة فقط.

ويمكن تشغيل **الدفع عبر الإنترنت (QRIS، حساب افتراضي، محفظة)** عبر بوابة PageHub من هنا بعد التحقق من هويتك. يذهب المال إلى قائمة **الرصيد**. راجع [الدفع الإلكتروني والرصيد](/ar/commerce/online-payments).

## عناوين العمل

**المتجر ← إدارة المتجر ← عناوين النشاط** — من أين تُشحن الطلبات.

| الحقل | ملاحظات |
| --- | --- |
| **اسم العنوان** | داخلي، مثل `المكتب والمستودع` |
| **اسم جهة الاتصال**، **الهاتف** | يُطبعان في إذن التسليم |
| **عنوان الشارع**، **المدينة / المنطقة**، **الرمز البريدي** | |

عنوان واحد يكون **الافتراضي** ويُنسخ إلى كل طلب جديد كعنوان مصدر. وأول عنوان يصير افتراضيًا تلقائيًا. ولا يمكن حذف العنوان الوحيد.

ويمكن تعديل عنوان المصدر في طلب ما — ويسري التعديل على ذلك الطلب وحده.

## الحسابات البنكية

**المتجر ← إدارة المتجر ← الحسابات البنكية** — إلى أين يحوّل المشترون.

<Shot src="/img/commerce/bank-accounts.webp">
صفحة الحسابات البنكية: بطاقات حسابات باسم البنك واسم صاحب الحساب ورقم الحساب مع زر نسخ، وعلامة «رئيسي» على أحدها.
</Shot>

| الحقل | ملاحظات |
| --- | --- |
| **البنك أو المزوّد** | BCA، Wise، PayPal — ما شئت |
| **باسم** | اسم صاحب الحساب |
| **رقم الحساب** | رقم أو IBAN أو معرّف |
| **ملاحظة** | الفرع أو SWIFT/BIC أو أي معلومة يحتاجها الدافع |

حساب واحد يكون **الرئيسي** ويظهر أولًا في الفواتير. وأول حساب يصير رئيسيًا تلقائيًا.

وكل حساب هنا يصير أيضًا خيارًا قابلًا للاختيار أمام المشترين في صفحة [الفاتورة العامة](/ar/commerce/public-invoice).

::: info ليست حسابات المنصّة
الحسابات هنا **حساباتك أنت** لاستقبال مدفوعات المشترين. أما حسابات دفع **اشتراك PageHub** فمختلفة وتديرها المنصّة — راجع [الترقية والدفع](/ar/account/billing).
:::

## إشعارات البريد

**المتجر ← إدارة المتجر ← إعدادات المتجر ← إشعارات البريد**. تُرسل رسائل الطلبات من **خادم SMTP الخاص بك** وهي **مطفأة افتراضيًا** — لا يُرسَل شيء حتى تفعّلها.

املأ المضيف والمنفذ واسم المستخدم وكلمة المرور وبريد المرسل واسمه والتشفير، مع **بريد إشعاراتك** (وإليه تصل إشعارات المالك).

ثم **احفظ وأرسل رسالة اختبار**.

::: warning الخادم غير المثبَت لا يُستخدم
حتى تنجح رسالة الاختبار، فالأحداث التي تفعّلها **لا ترسل شيئًا**. وهذا مقصود: إعدادات SMTP الخاطئة ستبتلع إشعارات الطلبات بصمت. وبعد النجاح تظهر علامة **SMTP موثّق**.

وتغيير أي شيء يمسّ الإرسال (المضيف، المنفذ، اسم المستخدم، التشفير، بريد المرسل، كلمة المرور) يمسح هذا التوثيق — أرسل اختبارًا جديدًا.
:::

الأحداث القابلة للتفعيل منفردة:

| الحدث | المستلم |
| --- | --- |
| طلب جديد | المالك |
| استلام الطلب | العميل |
| الطلب قيد التجهيز / مُرسل / مكتمل / ملغى | العميل |
| وصول الدفعة | المالك |
| إلغاء الطلب | المالك |

## بوابة الدفع

**المتجر ← إدارة المتجر ← إعدادات المتجر ← بوابة الدفع**. اربط حساب البوابة **الخاص بك** (Stripe أو PayPal أو Razorpay أو Paystack أو Flutterwave أو Mollie) ليدفع المشترون إليك مباشرة. ولمدفوعات QRIS والحسابات الافتراضية والمحافظ الإندونيسية استخدم [بوابة PageHub](/ar/commerce/online-payments). ويبقى التحويل البنكي اليدوي متاحًا بجانبها.

أدخل بيانات اعتماد البوابة، واختر **الوضع** (تجريبي للاختبار، مباشر للواقع)، ثم **سجّل رابط الويب هوك** المعروض هنا في لوحة البوابة لديك.

::: warning بلا ويب هوك لن تُوسَم الطلبات مدفوعة أبدًا
سينجح الدفع لدى البوابة، لكن PageHub لا يُخطَر. انسخ **نقطة الويب هوك** وسجّلها قبل استقبال مدفوعات حقيقية.
:::

وإن أبلغ الخادم بأن تشفير المدفوعات غير مُعدّ، فلا يمكن حفظ بيانات الاعتماد حتى يضبطه مسؤول المنصّة.
