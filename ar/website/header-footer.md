# الترويسة والتذييل

داخل الموقع، تُخزَّن الترويسة والتذييل **مرّة واحدة** على مستوى الموقع — ويسمّى ذلك *shell*. كل صفحة تخزّن محتواها فقط. وعند فتح الزائر لصفحة يركّبها PageHub معًا:

```
┌─────────── الترويسة (shell) ───────────┐
│                                        │
│             محتوى الصفحة               │
│                                        │
└─────────── التذييل (shell) ────────────┘
```

النتيجة: تغيير رقم هاتف في التذييل يُنجَز لثلاثين صفحة دفعة واحدة.

## إنشاء الـ shell

في تبويب **الصفحات** توجد بطاقة **الترويسة والتذييل**.

<Shot src="/img/website/shell-card.webp">
بطاقة «الترويسة والتذييل» فوق قائمة الصفحات، بعلامة حالة «فعّال» أو «لم يُنشأ بعد»، وسطر تعريفي، وزرّي «إنشاء ترويسة وتذييل» و«استخراجهما من صفحة قائمة».
</Shot>

طريقان:

### توليد جديد

اضغط **إنشاء ترويسة وتذييل**. يبني الذكاء الاصطناعي ترويسة (شعار مع خانة قائمة) وتذييلًا يتبعان مظهر الموقع وهويته.

### الاستخراج من صفحة قائمة

إن كانت لديك صفحة بترويسة جيدة، اضغط **استخراجهما من صفحة قائمة** واخترها. يرفع PageHub أول ترويسة (أو `<nav>`) وأول تذييل من تلك الصفحة إلى الـ shell العام؛ ويبقى الباقي محتوى لتلك الصفحة.

ثم صقّل النتيجة في محرّر الـ shell.

## محرّر الـ shell

افتحه بـ **تعديل الترويسة والتذييل**. هو المحرّر نفسه — الأوضاع المرئي والشيفرة والمحادثة كلها تعمل — غير أن ما تحرّره هو الترويسة والتذييل فقط.

<Shot src="/img/website/shell-editor.webp" wide>
محرّر الـ shell: لوحة ملفات على الجانب تعرض «الترويسة» و«التذييل» مع ملاحظة «تستخدمها كل الصفحات»، ومعاينة في الوسط تُظهر الترويسة أعلى والتذييل أسفل ومنطقة محتوى فارغة بينهما.
</Shot>

عند فتح صفحة عادية تستخدم الـ shell، يعرض المحرّر ملاحظة: *«الترويسة والتذييل مشتركان من shell الموقع. هنا تحرّر المحتوى فقط.»* — مع زر **تعديل الـ shell** بجوارها.

## خانة القائمة

داخل الترويسة عنصر خاص واحد:

```html
<nav data-eb-menu></nav>
```

يُترك **فارغًا عن قصد**. عناصر [قائمة التنقّل](/ar/website/navigation-menu) تُحقن هنا تلقائيًا عند تقديم الصفحة. لذا لا تحتاج — ولا ينبغي — كتابة روابط القائمة يدويًا في شيفرة الترويسة.

وإن كنت تكتب CSS الترويسة بنفسك، فتذكّر أمرين:

- تُحقن العناصر كقائمة من وسوم `<a>` **مباشرة** داخل ذلك الـ `<nav>` — بلا `<ul>` أو `<li>`. لذا ضع التباعد على الـ nav نفسه (`nav[data-eb-menu] { display:flex; gap:1.5rem }`)، لا على `nav ul`.
- ترويسة الهاتف عادةً فيها خانة ثانية، `<nav data-eb-menu-mobile></nav>`، لدرج القائمة.

## الصفحات التي لا تستخدم shell

الصفحات القديمة المبنيّة قبل نظام الـ shell ما زالت تحمل ترويستها وتذييلها، وتُعرض كما هي. لا شيء معطّل — لكنها أيضًا لا تتغيّر حين تحرّر الـ shell. لضمّها، انسخ محتواها إلى صفحة جديدة، أو استخدم **استخراجهما من صفحة قائمة**.

صفحات الهبوط **لا تستخدم** shell أبدًا: هي مستقلّة، بترويستها وتذييلها.
