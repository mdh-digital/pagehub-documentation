# إدارة الصفحات

تبويب **الصفحات** هو قاعدة الموقع: منه تنشئ الصفحات وترتّبها وتنشرها وتدخل إلى المحرّر.

<Shot src="/img/website/pages-tab.webp" wide>
تبويب الصفحات: قائمة الصفحات بمقابض سحب وعناوين وشارة «الرئيسية» على الأولى، وعدد المشاهدات، وحالة النشر/المسودّة، وأزرار الفتح والتعديل والقائمة. وفي العمود الجانبي بطاقة «الترويسة والتذييل» ثم لوحة «لمحة سريعة» بالرابط العام وعدد الصفحات وإجمالي المشاهدات والنطاق المخصّص وحالة المدوّنة.
</Shot>

## صفحة جديدة

اضغط **صفحة جديدة**. يظهر مُنتقي القوالب:

- **فارغة** — صفحة خالية تملؤها بنفسك.
- **قوالب صفحات** — تخطيطات جاهزة (من نحن، تواصل، الأسعار، وغيرها)، مع حقل بحث فوقها.

بعد الاختيار تدخل المحرّر مباشرة.

::: tip الصفحة الأولى تعرض استخراج الـ shell
إن لم يكن لموقعك ترويسة/تذييل عامّان ولديك صفحة بترويسة جيدة، يعرض هذا الحوار رفع ترويسة تلك الصفحة وتذييلها إلى shell عام. ضغطة واحدة، وكل صفحة بعدها تحتاج المحتوى فقط.
:::

## الترتيب والصفحة الرئيسية

الصفحة **الأعلى تصير الرئيسية** — وهي التي تُقدَّم عند فتح عنوان الموقع دون ذكر صفحة.

غيّر الترتيب بسحب المقبض على حافة البطاقة. وبلوحة المفاتيح يمكن تركيز المقبض وتحريكه بالأسهم — وتُعلَن الحركة لقارئات الشاشة.

اختصار: قائمة ⋯ لأي صفحة ← **اجعلها الصفحة الرئيسية**.

## إجراءات كل صفحة

| الإجراء | ماذا يفعل |
| --- | --- |
| **تعديل** | فتح المحرّر |
| **فتح في تبويب جديد** | عرض النسخة المنشورة |
| **نسخ الرابط** | نسخ الرابط العام للصفحة |
| **اجعلها الرئيسية** | نقلها إلى الأعلى |
| **نسخ** | نسخة من الصفحة كمسودّة |
| **إلغاء النشر** | تعود مسودّة، ويتوقّف عنوانها |
| **حذف الصفحة** | نهائي |

## الحالة

تعرض كل صفحة **منشورة** أو **مسودّة**، ووقت آخر تعديل، وعدد مشاهداتها. وتلخّص لوحة **لمحة سريعة**: `3 منشورة · 2 مسودّة`.

## معرّفات الصفحات (slug)

المعرّف هو الجزء الأخير من العنوان: `.../halawiyat/about-us`. يُضبط في المحرّر بجوار عنوان الصفحة.

القواعد: حروف صغيرة وأرقام وشرطات. وفريد داخل الموقع الواحد — لا يمكن لصفحتين منشورتين تقاسم المعرّف نفسه.

::: warning بعض المعرّفات محجوزة
‏`blog` و`invoices` و`products` و`cart` و`checkout` و`p` لا تصلح للصفحات العادية — فهي تخصّ وحدات المدوّنة والمتجر وصفحات الهبوط. سيرفضها PageHub.
:::

::: warning تغيير المعرّف يقتل الروابط القديمة
إن كانت الصفحة منشورة وعنوانها منتشر، فتغيير المعرّف يحوّل الروابط القديمة إلى 404. غيّره عند الضرورة فقط.
:::

## بطاقة الترويسة والتذييل

تعرض البطاقة العلوية حالة الـ shell:

- **فعّال** — موجود، والزر **تعديل الترويسة والتذييل**.
- **لم يُنشأ بعد** — الزر **إنشاء ترويسة وتذييل**، مع **استخراجهما من صفحة قائمة**.

التفاصيل: [الترويسة والتذييل](/ar/website/header-footer).

## لمحة سريعة

الملخّص الجانبي: **الرابط العام** (قابل للنسخ)، وعدد **الصفحات**، و**إجمالي المشاهدات**، وحالة **النطاق المخصّص** (`لم يُضبط` إن لم تعدّه).
