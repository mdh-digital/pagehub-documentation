# Template website

Template website adalah **potret seluruh website**: semua halaman, header & footer, tema, menu, pengaturan blog, SEO, dan media di dalamnya. Dipakai buat memulai website baru tanpa mengulang dari nol.

Beda dengan [template landing page](/landing-pages/landing-templates) yang isinya cuma satu halaman.

## Memakai template

Dari **Websites** → **Website baru** → **Pakai Template**.

<Shot src="/img/website/template-gallery.webp" wide>
Galeri template website: kartu-kartu bergambar thumbnail dengan nama template dan kategori, filter kategori di atas, dan kotak pencarian. Tiap kartu punya tombol Detail dan Preview.
</Shot>

- **Preview** membuka pratinjau situsnya; kamu bisa pindah-pindah halaman di dalamnya.
- **Gunakan** menyalin template jadi website baru milikmu.

Yang terjadi saat dipakai:

1. Website baru dibuat, beserta seluruh halamannya.
2. Tema, menu, brand, header/footer, dan pengaturan blog ikut tersalin.
3. Gambar-gambar di dalam template **disalin ke [File Manager](/media/file-manager) organisasimu**, dan tautan di HTML-nya diarahkan ke salinan itu. Jadi template asli dihapus pun situsmu nggak ikut rusak.
4. Kuota website berkurang satu.

Setelah itu semuanya milikmu — ubah sebebasnya.

## Menyimpan website jadi template

Berguna buat agensi: bikin satu situs "resep" yang bagus, lalu pakai berulang untuk klien-klien berikutnya.

Dari halaman website, klik **Jadikan template** (atau lewat **Pengaturan** → **Template & ekspor**).

<Shot src="/img/website/save-as-template.webp">
Dialog "Jadikan template": kolom Nama template, Deskripsi opsional, dropdown Kategori, pengunggah Thumbnail, dan catatan bahwa template ini privat untuk organisasi kamu.
</Shot>

Isian yang diminta:

| Kolom | Keterangan |
| --- | --- |
| **Nama template** | Nama yang muncul di galeri |
| **Deskripsi** | Opsional |
| **Kategori** | Dari daftar kategori yang disediakan platform |
| **Thumbnail** | Gambar kartu di galeri |

## Visibility

| Visibility | Siapa yang lihat |
| --- | --- |
| **Privat** | Cuma organisasimu |
| **Global** | Semua pengguna PageHub |

Template yang kamu simpan sendiri selalu **privat**. Template global disediakan dan dikelola oleh tim platform.

## Yang ikut dan yang nggak ikut

**Ikut tersalin:**

- Semua halaman beserta HTML-nya
- Header & footer (shell)
- Tema global, menu navigasi, brand brief
- Pengaturan blog dan tampilannya
- SEO default
- Gambar dan file media yang dipakai halaman-halaman itu

**Nggak ikut:**

- Domain kustom
- Isi tracking & pixel
- Artikel blog
- Produk, pesanan, dan pengaturan toko
- Leads dan submission form
- Statistik & views

Alasannya sama untuk semua: itu data milik satu situs tertentu, bukan bagian dari desainnya.

## Unduh ZIP

Di **Pengaturan** → **Template & ekspor** ada juga **Unduh ZIP** buat membawa salinan HTML situsmu keluar dari PageHub. Berguna sebagai arsip, atau kalau kamu mau menyerahkan berkasnya ke klien.
