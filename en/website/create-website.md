# Create a website

A website is a set of pages under one address, one theme and one menu. If you need more than one page — or you need a blog or a store — a website is what you want, not a [landing page](/en/landing-pages/create-landing-page).

## Three ways to start

Open **Websites** → **New website**.

<Shot src="/img/website/new-website-options.webp">
The "New website" window over the website list, with three cards: Use a template, Build with AI (labelled "Fastest"), and Start blank. Each has an icon and a one-line explanation.

| | What you get | AI credits |
| --- | --- | --- |
| **Use a template** | A complete site with all its pages, ready to edit | Not used |
| **Build with AI** | A homepage assembled from your description | Used |
| **Start blank** | A website with no pages — you build them | Not used |

### Use a template

Pick from the gallery, preview it, click **Use**. Everything in the template — pages, header/footer, theme, menu and its images — is copied to you. The copy is yours to change; the original template is untouched.

Media inside the template is copied into your organisation's [File Manager](/en/media/file-manager), in a folder named after the new website's address.

See [Website templates](/en/website/website-templates).

### Build with AI

1. **Website name** — what you'll see on the dashboard, e.g. `Sweet Cakes`.
2. **Address** — the part that appears in the URL, e.g. `sweet-cakes`. Lowercase, digits, hyphens.
3. **What should this website be about?** — describe the business. Say what you sell, who for, what it should feel like, and which sections you want.
4. **Use blog / articles** — turn on if you want the blog module. Can be enabled later.

After **Create**, AI asks a few questions, drafts a plan, then assembles the page section by section. See [How AI builds a page](/en/ai/how-generation-works).

::: tip That first description sticks around
The name, description and the brand brief AI synthesises at this step are stored on the website. Every page and article you generate **afterwards** reads them, so tone and style stay in the family. Spend a minute or two here.
:::

### Start blank

Just a name and an address. The website starts with no pages; you add them from the **Pages** tab.

## After the website exists

The order that avoids doing work twice:

1. **[Header & footer](/en/website/header-footer)** first — used by every page.
2. **[Theme](/en/website/theme-and-brand)** — global colours and fonts.
3. **The rest of the pages** ([Manage pages](/en/website/pages)).
4. **[Navigation menu](/en/website/navigation-menu)** once pages exist, so you can just point at them.
5. **[Custom domain](/en/website/custom-domain)** when you're ready to go live properly.

## Quota

Each website consumes one **website** slot in your plan. Landing page quota is counted **separately** — a full website quota doesn't stop you creating landing pages, and vice versa. Check what's left in **Billing**, or see [Plans & quota](/en/account/plans-and-quota).

## Duplicating and deleting

The website card's ⋯ menu offers:

- **Duplicate** — a full copy, named with a `(copy)` suffix. Consumes one quota slot.
- **Delete website** — removes the website **and all of its pages**. This can't be undone; PageHub asks for confirmation and names how many pages go with it.
