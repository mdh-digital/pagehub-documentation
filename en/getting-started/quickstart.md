# Build your first page

The goal: from an empty account to one page live on the internet. About ten minutes, most of it spent watching AI type.

## 1. Pick a workspace

Look at the workspace picker above the sidebar. A new account already has one default workspace — use it for now. If you work with clients and want each one separated, [create a workspace](/en/team/workspaces) now, before anything lives in it.

## 2. Create a website

Open **Websites** → **New website**. Three routes:

| Option | When to use it |
| --- | --- |
| **Use a template** | Fastest. Pick from the gallery and get a complete site |
| **Build with AI** | Describe your business; AI asks a few questions, then assembles the pages |
| **Start blank** | You build everything yourself |

<Shot src="/img/getting-started/new-website-options.webp">
The "New website" screen with three cards side by side: Use a template (marked "Fastest"), Build with AI, and Start blank.
</Shot>

For this guide we'll use **Build with AI**.

1. Fill in **Website name** — say `Sweet Cakes`.
2. Fill in **Address** — the part that appears in the URL, e.g. `sweet-cakes`. Lowercase letters, digits, hyphens.
3. Under **What should this website be about?**, write a paragraph or two. The more concrete, the better:

   > A home bakery called "Sweet Cakes". We sell birthday and custom cakes around Bandung. It should feel warm and sweet, pastel colours. I need a product catalogue, customer testimonials, a short story about the owner, and a WhatsApp ordering button.

4. Turn on **Use blog / articles** if you want a blog (you can enable it later too).
5. Click **Create**.

## 3. Answer the AI's questions

AI doesn't start writing straight away. It asks a few things first — who the buyers are, what visual style you want, what matters most — then drafts a page plan, and only then assembles each section.

<Shot src="/img/getting-started/ai-build-questions.webp">
The AI build screen: a step counter at the top, one multiple-choice question ("What visual theme do you want?"), and answer cards with small previews.
</Shot>

As it runs, each section appears one at a time in the preview. Details in [How AI builds a page](/en/ai/how-generation-works).

## 4. Tidy up in the editor

When it finishes, you land in the **page editor**. Three modes sit in the top toolbar:

- **Visual** — click any element to change text, colour, image, or move it.
- **Code** — raw HTML, for when you'd rather edit it directly.
- **AI** — chat. Type "make it green" or "drop the testimonials section" and AI does it.

<Shot src="/img/getting-started/editor-first-look.webp" wide>
The page editor: top toolbar with the page title, Visual/Code/AI mode switch, desktop/tablet/mobile viewport picker, a "Saved" indicator, plus Save and Publish buttons. Outline panel on the left, page preview in the middle.
</Shot>

Save with <kbd>Ctrl</kbd>+<kbd>S</kbd> or the **Save** button. The toolbar shows the state: *Unsaved* → *Saving…* → *Saved*.

## 5. Build the header and footer once

Go back to the website (the **Back to website** button). On the **Pages** tab there's a **Header & Footer** card.

This is what makes a multi-page site bearable: build the header and footer **once**, and every page uses them. If AI created your website, the shell is usually already there. If not, click **Create header & footer**, or **Extract from an existing page** to lift the header and footer out of a page you've already built.

Read [Header & footer](/en/website/header-footer).

## 6. Publish

In the editor, click **Publish**. The page goes live immediately.

Copy its address with **Copy URL**, or open it with **Open site**. It looks roughly like this:

```
https://<workspace>.pagehub.id/sweet-cakes
```

The page **at the top of the page list** becomes the website's **homepage**. Reorder by dragging page cards, or use the ⋯ menu → **Set as homepage**.

The editor toolbar after publishing: the button becomes Unpublish, Copy URL and Open site appear, and a "Published" badge sits beside the page title.
</Shot>
