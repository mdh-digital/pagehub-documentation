# Abandoned carts

**Commerce → Abandoned cart**. Visitors who started ordering but never finished — a follow-up list, not just a statistic.

<Shot src="/img/commerce/abandoned-carts.webp" wide>
The Abandoned cart page: four stat cards (open, converted, lost, value held), then a table with Visitor, Page, Filled, Value, Owner and Last seen columns; status filter and search box above.
</Shot>

## How the data arrives

Shop pages send the form fields a visitor is filling in to PageHub **before** they hit the order button. If they leave, what they'd typed so far is still there.

If they complete checkout, the record is closed and marked **Converted** — so you never call someone who has actually bought.

## The summary cards

| Card | Contents |
| --- | --- |
| **open** | Not closed, ready to follow up |
| **converted** | Ended as an order |
| **lost** | You marked it as not going anywhere |
| **value held** | Total value still sitting in open carts |

## What each row holds

| Column | Notes |
| --- | --- |
| **Visitor** | The name they typed, or *Anonymous visitor* |
| **Page** | Where they stopped |
| **Filled** | Which fields they'd already completed |
| **Value** | The estimated cart value |
| **Owner** | Who's following up |
| **Last seen** | When they were last active |

Open a row to see everything **they'd filled in**.

## Following up

- **Chat on WhatsApp** — appears when a phone number was entered. Opens WhatsApp with that number.
- **Follow-up note** — write what happened when you contacted them. This is what keeps the list useful for whoever picks it up next.
- **Mark as lost** — for the ones clearly not going anywhere, so they're not chased repeatedly.
- **Assign to…** — several rows can be selected and assigned to one person.

## When the data is empty

Visitors who leave before typing anything are recorded as **Anonymous visitor** with no contact details. Rows like that are useful as a number (how many people back out at that point), not as a call list.

If most rows are empty, that's a signal about your checkout page — not about the list.

## Deleting

**Delete cart** removes the data permanently. For the ones that simply didn't go anywhere, **Mark as lost** is better: the row leaves the queue but still counts in reports.

## Reports

There's a dedicated abandoned cart report under **Reports → Abandoned cart**, with trends over time. See [The ten reports](/en/reports/overview).
