# Redeem an AppSumo code

If you bought PageHub through **AppSumo**, redeem your code under **Billing → AppSumo**.

## How to redeem

1. Open your AppSumo purchase email, or your AppSumo account — the code is under **Products**.
2. Paste it into the box and press **Redeem**.
3. Your plan is upgraded immediately. No card, no renewals.

## Stacking codes

Codes can be **stacked**. Each redeemed code moves the same account up to the next tier — websites, landing pages, storage and AI credits all increase.

Redeem them one at a time; the quota figures at the top always show the combined total.

## Your licences

The table below records every code you've redeemed, with its status:

| Status | Meaning |
| --- | --- |
| **Active** | In force |
| **Refunded** | You returned this purchase |
| **Deactivated** | Withdrawn by AppSumo |

With no active licences, your plan returns to Free.

## If a code is rejected

| Message | What it means |
| --- | --- |
| *"This doesn't look like a code"* | Copy one whole line from AppSumo, with no trailing spaces |
| *"That code wasn't found"* | Check it against your AppSumo account |
| *"That code has already been redeemed"* | On this account or another |
| *"That code is no longer valid"* | Probably refunded or withdrawn |

## AI credits on lifetime plans

AppSumo plans are lifetime plans, and their credits are granted **once, up front** — into the top-up balance that never expires. There's no monthly refill.

When they run out, buy credits under **Billing → AI Credit**. See [AI credits](/en/ai/credits).

## Refunds

If you request a refund through AppSumo, the licence is marked **Refunded** and your account drops to Free through the same grace period as an ordinary subscription — you get time to tidy your content before anything is removed.

See [When a subscription lapses](/en/account/subscription-lapse).

## Adding white label

Lifetime plans can't be upgraded to another plan without losing their lifetime nature. If you need white label, buy it as an [add-on](/en/account/add-ons) — that's the route provided for exactly this situation.
