# Tur antarmuka

Sekali paham letak barangnya, sisanya gampang. Layar PageHub selalu punya tiga bagian: **sidebar** di kiri, **isi halaman** di tengah, dan **panel bantu** yang muncul sesuai konteks.

## Sidebar

### Pemilih workspace

Tepat di bawah logo. Klik untuk pindah ke workspace lain — **seluruh layar ikut berganti**: daftar website, landing page, dan File Manager semuanya menyempit ke workspace itu.

Pilihanmu diingat browser, jadi besok kamu balik ke workspace yang sama. Kalau workspace-nya dihapus atau aksesmu dicabut, PageHub otomatis balik ke workspace lain yang masih boleh kamu buka.

### Grup Ruang kerja

| Menu | Isinya |
| --- | --- |
| **Dashboard** | Ringkasan, "Lanjutkan" (website terakhir diubah), dan "Perlu perhatian" |
| **Websites** | Semua website di workspace aktif |
| **Landing Page** | Landing page lepas |
| **Leads** | Semua isian form yang masuk |
| **File Manager** | Gambar dan file media, plus foldernya |
| **Block List** | Blokir IP pengunjung yang mengganggu |
| **Bantuan** | Kirim tiket ke tim PageHub |

### Grup Bisnis

| Menu | Isinya |
| --- | --- |
| **Billing** | Paket aktif, kuota terpakai, upgrade, add-on, riwayat tagihan |
| **Workspace** | Bikin & kelola workspace, atur siapa anggotanya |
| **Brand** | Ganti merek PageHub jadi merekmu, dan atur tampilan default tim |
| **Tim** | Undang anggota, atur peran & akses per-website |

Menu **Brand** dan **Tim** cuma muncul buat owner/admin organisasi.

### Menu akun

Di paling bawah sidebar: nama dan email kamu. Klik untuk buka **Profil**, **pindah organisasi** (muncul cuma kalau kamu ada di lebih dari satu), dan **Keluar**.

## Tweaks — panel tampilan

Ikon palet di dekat menu akun membuka panel **Tweaks**: drawer setinggi layar dari sisi kanan (dari kiri kalau bahasa yang aktif Arab).

Lima hal yang bisa diatur:

| Kontrol | Efeknya |
| --- | --- |
| **Warna aksen** | Warna tombol dan penanda aktif di seluruh aplikasi |
| **Terang / gelap** | Mode tampilan |
| **Tone** | Kehangatan warna netral (cool / neutral / warm) |
| **Gaya menu** | Sidebar pakai label + ikon, atau ikon saja |
| **Radius** | Seberapa membulat sudut kartu dan tombol |

<Shot src="/img/getting-started/tweaks-panel.webp">
Panel Tweaks terbuka di sisi kanan: pilihan warna aksen berbentuk lingkaran, tombol terang/gelap, pilihan tone, gaya menu, dan slider radius.
</Shot>

Yang penting dipahami: pilihan ini **tersimpan di akunmu, bukan cuma di browser**. Jadi kamu buka PageHub dari laptop lain, tampilannya ikut.

Dan ada dua lapis:

1. Kalau kamu **pernah** menyetel sendiri, pilihan pribadimu yang menang.
2. Kalau **belum pernah**, kamu ngikut *tampilan default tim* yang diatur owner di halaman [Brand](/team/brand-white-label). Waktu agensi ganti house style, tampilanmu ikut berubah.

Owner bakal lihat tombol **Jadikan default tim**; siapa pun yang punya pilihan sendiri bakal lihat **Ikuti default tim** buat balik ngikut.

## Mode rail

Klik tombol di ujung sidebar buat menciutkannya jadi **rail** — cuma ikon. Nama menunya tetap kebaca sama pembaca layar, dan bakal muncul sekilas kalau kamu arahkan kursor ke rail-nya.

Di layar kecil, sidebar berubah jadi drawer yang dibuka lewat tombol menu.

## Bahasa & mata uang

Di header ada dua pemilih bersebelahan:

- **Bahasa** — 7 bahasa: Indonesia, English, العربية (kanan-ke-kiri), Deutsch, Español, Tiếng Việt, Français.
- **Mata uang** — cuma mengubah **cara harga ditampilkan**. Pembayaran tetap dalam Rupiah. Lihat [Upgrade & pembayaran](/account/billing).
